# ⌨️ Typing — Tezlik Testi Ilovasi

Zamonaviy typing speed test ilovasi. React, Next.js va TypeScript asosida ishlab chiqilgan.

## 🚀 Xususiyatlari

- ⏱️ Real vaqtda tezlik o'lchash (WPM)
- ✅ Aniqlik foizini hisoblash
- 🎯 Har xil qiyinlikdagi matnlar
- 🌙 Dark/Light mode
- 📊 Natijalar tarixi
- 🎨 Zamonaviy animatsiyalar (Framer Motion)
- 📱 Responsive dizayn

## 🛠️ Texnologiyalar

| Texnologiya | Versiya |
|-------------|---------|
| Next.js | 16.x |
| React | 19.x |
| TypeScript | 5.x |
| Tailwind CSS | 4.x |
| Zustand | 5.x |
| Framer Motion | 12.x |

## 📦 O'rnatish

```bash
# Clone qilish
git clone https://github.com/ziiyodullayevv/typing.git

# Papkaga o'tish
cd typing

# Dependentliklarni o'rnatish
npm install

# Development server
npm run dev
```

🌐 Brauzer da http://localhost:3000 oching.
